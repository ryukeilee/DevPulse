## 接受的候选

设置页输入不存在的路径或普通文件路径并点击「添加」时，基线 `ScanScheduler.addCustomPath` 拒绝路径，不写入扫描配置，但 `SettingsView` 无条件清空输入。失败原因只显示在默认折叠的「查看诊断明细」中，且将不存在目录也描述为权限失效。目录选择入口也无条件清空输入。

复现方法：在临时目录下准备一个不存在的 `missing` 路径和一个普通文件 `not-a-directory`，分别在自定义扫描目录字段输入后点击「添加」。基线结果为目录未添加、输入被清空，添加区域没有失败反馈。此结论经两个独立的只读代码检查确认；没有声称执行过基线 GUI 复现。

修复让 `addCustomPath` 返回接受/拒绝结果，已有调用者可忽略返回值。设置页仅在接受时清空输入；拒绝时保留输入，在添加区域显示说明，编辑输入时清除旧提示。文本输入和目录选择共用结果处理。有效目录、重复添加和内置目录启用沿用已有行为，不创建输入路径，不增加扫描或文件内容读取。

可验证收益是失败后无需重新输入路径，也无需展开诊断寻找失败原因。收益属于错误恢复和交互反馈，不作为性能提升结论。
